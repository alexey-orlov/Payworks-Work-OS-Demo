# Competitors

One folder per tracked competitor.

**Read this when:** You need the teardown for a specific competitor.

Folder name = slug: immutable kebab-case, the same name used in matrix columns and landscape lines. Each folder holds `teardown.md` — the competitor's living profile, copied from [competitor-teardown-template.md](../../handbook/templates/competitor-teardown-template.md) and edited in place — plus its own 5-line `CLAUDE.md` stub.
