# Commands — house-name aliases

Thin slash-command aliases mapping Payworks' own artifact names onto the canonical,
master-maintained skills. Each file invokes its skill and nothing else — no skill logic
lives here, so master updates keep applying to this instance.

**Read this when:** a document or the deck says `/product-brief-draft` and you want to know
which skill actually runs.

## Contents

### Files

- [micro-job-challenge.md](micro-job-challenge.md) — `/micro-job-challenge` → `job-spec-challenge`. Challenge a drafted Micro Job before it is agreed.
- [micro-job-draft.md](micro-job-draft.md) — `/micro-job-draft` → `job-spec-draft`. Write the buildable contract for ONE Micro Job.
- [micro-jobs-breakdown.md](micro-jobs-breakdown.md) — `/micro-jobs-breakdown` → `jobs-breakdown`. Cut an agreed initiative into Micro Jobs, sequenced riskiest-first.
- [pm-ba-handoff.md](pm-ba-handoff.md) — `/pm-ba-handoff` → `pm-handoff`. Run the PM→BA handoff readiness check.
- [product-brief-challenge.md](product-brief-challenge.md) — `/product-brief-challenge` → `prd-challenge`. Run the independent challenge panel over a drafted Product Brief.
- [product-brief-draft.md](product-brief-draft.md) — `/product-brief-draft` → `prd-draft`. Draft or iterate a Product Brief — the living spine of feature definition.

## Writers

`/customize-os` target `naming-conventions` (its alias route). Adding or removing an alias
belongs to that target, so the mapping and the status file stay in step.
